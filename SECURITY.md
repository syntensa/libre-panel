# Security

Libre Panel runs a local web server for the editor (127.0.0.1 only) and loads
themes that other people share. Issues that let a theme run code, read or
write files outside its folder, or let a website talk to the editor are
security bugs.

Please report them privately through GitHub's
[security advisories](https://github.com/syntensa/libre-panel/security/advisories/new)
rather than a public issue. You will get an answer within a week.
